# Problem Discovery results

Store only aggregate, non-identifying results and editorial decisions here.

Each dated report should state:

- market and collection dates
- Google source settings and windows
- clusters that passed or failed each stage gate
- search-results answer-gap findings
- micro-answer sample sizes and raw event counts
- the pre-registered primary outcome
- confidence intervals and any multiplicity correction used
- editorial decision and its limits

Do not commit Google account credentials, OAuth tokens, raw GA4 exports, visitor-level data, usernames, copied community posts, or private URLs.
